# Tarea 1

## Instrucciones

Entra a esta carpeta:

```bash
cd codigoFuente/tarea1
```

Para abrir la aplicación gráfica:

```bash
python3 main.py
```

Para usar la CLI:

```bash
python3 cli.py --text "ejecutar una función cuando se suba una imagen"
```

Para correr las pruebas:

```bash
python3 -m unittest discover -s tests -v
```
